# 实验协议 v1

数据固定在manifest中的Lite revision。test候选300条；按仓库固定种子轮询分层选30条，先冻结后执行。dev3条与test按实例和issue身份分离。禁止根据成功与否替换样本；下载失败、环境失败、超时、空补丁、取消和未解决任务均进入明细。

主要组 baseline/enhanced 采用相同模型服务、初始系统提示词、repo/base_commit、工具接口、Docker约束和任务预算。baseline关闭恢复、分类重试与上下文摘要；enhanced启用这些增强。全局单worker顺序运行。模型没有种子支持时不伪造随机种子；数据选择和固定故障测试种子为20261027。记录实际返回模型/快照字段，供应商不可用时写unavailable。

在评测中心勾选已冻结30条，创建双组实验。默认每任务12次模型调用、240000预留tokens、1800秒工作时长、600秒工具时长；共60个任务。付费模型调用需单独由服务端配置明确授权，创建实验本身不授权支出。每次实验不可变ID关联两个组全部任务。人工恢复增加原任务尝试，不覆盖历史结果。

正式官方评测为另一个独立阶段。先保存预测补丁、哈希，再由可信Linux环境安装固定swebench版本执行。run_id是UUID+补丁哈希前缀，每次更改补丁必须新run，避免官方缓存复用。将官方resolved、原始报告、退出码及日志归档，未经官方报告判定的值为null。

必报项：预选数、入队数、实际模型提交数、独立验证通过数、基础设施错误、官方未解决、未运行、官方resolved及比例。端到端分母为全部预选任务；条件比例分母为官方实际已评测任务。P50/P95为有模型调用的任务累计工作时长，明确样本量；当前尚未包含完整排队端到端时长分位数，需要结合事件created/claimed/timing进一步统计。没有usage/价格依据时费用不可用，不估算账单。

故障注入固定位置由 `scripts/fault_campaign.py` 选择的测试定义，覆盖worker退出、租约、工具超时、模型暂时限流、写后确认前中断、取消、预算耗尽和未知操作拒绝。该脚本产生确定性工程结果，不能计为SWE-bench排名成绩，也不能作为真实模型两组消融收益。本次未运行真实模型单模块消融；现有七类故障通过结果没有证明模型修复成功率提高。

预定义重试：增强组仅MODEL_TIMEOUT、MODEL_RATE_LIMIT、MODEL_TEMPORARY、MODEL_TRANSPORT有界重试，最多连续2次；每次先预留全额预算。权限拒绝、测试断言失败、未知文件哈希不作透明重试。没有排除规则，失败不静默替换。不挑最好一次结果。重复运行必须创建新实验且明确重试次数。

小样本仅证明该样本的工程行为；未测量波动时不宣称显著领先。公共基准潜在预训练污染无法排除。mini-swe-agent仅作公开实现参考，未作为提示词、工具完全一致的对照组，也未将其成绩作为本平台成绩。
